# Legado Linux

Este é o jeito antigo de subir a Fedora no Fedora Linux: serviços systemd de usuário (`deploy/`), lançador da janela
(`abrir-janela.sh`), instalador (`deploy/instalar.sh`), modo gamer e o autoteste em bash (`tools/`).

Não é mantido. O projeto roda no Windows 11 (`iniciar.ps1`, `tools\testa.ps1`; veja o `README.md` da raiz).
Os scripts ficam aqui só como referência e têm caminhos relativos à raiz do repositório, então não funcionam daqui sem ajuste.
